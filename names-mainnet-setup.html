Prepare the price key.

The Treasury job signs NETA prices with a dedicated key. Create it here, save a private backup, then install it in GitHub. No wallet connection or transaction is needed for this step.

1. Create or restore the key

This page handles the key locally. Only the public key is remembered in this browser. Keep the private backup; a reload removes the private key from this page.

No price key loaded.

2. Save the backup and GitHub secret

Download the private backup and keep it somewhere safe. Do not send the PEM file or private key in chat, and do not add it to the repository.

Open GitHub → New repository secret. Use the name NNS_PRICE_SIGNING_KEY. Copy the private key below, paste it into GitHub’s Secret field and save.

The private key is copied only when you click. Keep it out of screenshots and messages. Once saved in GitHub, copy the public key to replace it in your clipboard.

3. Prepare contract deployment

Download the public plan or share the public key above. It pins the registry and profile artifacts, the real NETA token and the main NETA DAO as fee recipient and administrator. New purchases start paused.
