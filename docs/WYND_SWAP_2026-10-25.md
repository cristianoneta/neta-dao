## Pool and asset checks

The five pair addresses reuse the Treasury collector's existing registry. Live
read-only checks on 25 October confirmed each contract uses code 2289, the
configured two assets, XYK type and a 30-bps pool fee. Both CW20 assets report the
expected symbol and six decimals. The three IBC denomination hashes were
recomputed from their live structured traces. All ten directions returned valid
read-only contract simulations; no transaction was broadcast. Observed public pair/reserve responses are
retained in `tests/fixtures/wynd-five-pools.json`; these are test evidence, not
production market data. The primary pair source was reviewed at wynddex commit
`8d133237def44507aea8030502e3bc00519e7937`.

The USDC denomination is the existing Axelar USDC asset on Juno, explicitly
labelled in the selector. ATOM and OSMO are likewise the configured Juno IBC
representations. A six-asset selector chooses only one of the five direct pools;
when needed it updates the opposite asset and clears the amount and old quote.
It never silently routes through an intermediary pool. JUNO/NETA stays the default.

Each pool is verified independently. The selected pair, exact asset identities,
code, type, fee, CW20 precision and reserves are checked before quotes and again
before signing. Native offers attach the exact IBC/native denomination; CW20
offers send to the selected pair with the exact ask asset. Review binds both
assets, pair, amount, tolerance and minimum. JUNO fee coverage is checked even
when neither swapped asset is JUNO. Confirmation matches the exact receiving
token contract or native/IBC denomination and wallet. Ambiguous broadcasts keep
the shared pending journal; no retry bypass is introduced.

## Dollar valuation

Reserves refresh on entry, manual refresh and every minute while the page is
visible and idle. The existing timestamped Juno Treasury snapshot supplies exact
native-asset USD prices; its 36-hour freshness ceiling remains. Independently
priced sides are summed. A side without an external price is estimated from the
same pool's reserve ratio and the available priced side. Consequently NETA, WYND
and sometimes OSMO use an indicative pool-derived price. The details disclose
this and both observation times. USDC is not silently assumed to be one dollar.
Missing prices/reserves are unavailable, never zero; unavailable USD blocks
signing for that pool. These five selected pools are sorted by their current
estimated liquidity, not advertised as a fresh ranking of every WYND pool.
