# Informal work-time estimate — 5 October 2026

Requested by the owner during NNS price-service development; answered in English.
Best estimate: **90–95 collaborative working hours**, plausible range **80–105**.

| Project | Estimated hours |
| --- | --- |
| netareborn.com / neta-website | 40–50 |
| dao.netareborn.com / neta-dao, excluding faucet | 35–45 |
| UNI-7 faucet, hosting and wallet testing | 5–10 |

This is not a timesheet, personal hands-on time, billable-time statement or a
counterfactual estimate of how long a hired team would take. The DAO row includes
governance, Treasury, RELAY and NNS; faucet work is separated to avoid double count.

Basis: available conversation windows and non-merge development commit timestamps
on the two repositories' main histories, 11 September–5 October 2026. Automated
collector/bot updates were excluded. The inspected histories contained 230
website and 186 DAO non-bot/non-merge commits; commit counts are evidence of
activity, not hours. Clustering the combined timelines with 60–120-minute gap
cutoffs and a 15-minute lead-in per cluster gave about 81–95 elapsed session hours.
Cross-project overlapping clusters were counted once for that combined check.
The rounded project allocation is judgment based on scope and session history.

Uncommitted discussion, design, wallet testing, build/deployment waits, breaks and
work done outside these chats are not precisely measurable from these sources.
Do not present the estimate as tracked time or reuse it as a fixed project budget.
