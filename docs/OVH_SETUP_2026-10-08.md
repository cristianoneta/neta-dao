Updated 8 October 2026. This is the public migration summary. The full operator
record is retained privately outside Git. Follow the
[documentation policy](DOCUMENTATION_PRIVACY.md); access details, host inventory,
backup receipts and exact operator commands are not included here.

## Confirmed progress

- Source transfer and the snapshot-only HTTPS edge were completed. The owner
  verified the 26 public files and rejection of four private/unlisted paths.
- The corrected Cloudflare proxy was published. A later operator check reported
  HTTP 200 and the server snapshot marker for the signed NNS price on both
  website origins. Complete all-path byte/fallback acceptance remains open.
- The original NNS signing key was installed privately and one manual main
  collector run was reported successful. This is not evidence that all collector
  data or historical accounting is current. Automatic timers remain inactive.
- A preliminary encrypted copy of both production databases was transferred and
  verified. This proves copy integrity and decryptability, not application-level
  restoration or a completed backend migration.

2. Verify target runtime configuration and containers, admission settings and

3. Complete an application restore drill with a separate synthetic identity.
   The real fresh-browser user drill remains deferred.
4. Freeze all source writes for a fresh final database export, verify the copies,
   coordinate endpoint/origin configuration and enable exactly one writer.
5. Retain Render through the agreed rollback window. After new target writes,
   rollback requires those newer records, not an earlier snapshot.

Render remains the production backend; no target backend startup or cutover is
confirmed. Resume from the private operator handoff before performing host actions.
